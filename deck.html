❌ Problem

✅ Solution – LGT Reward Pools

Three pool types for projects:

  • Standard Pool: Projects pay refundable creation fee; users deposit USDC → earn $LGT (2x–5x multiplier). 20% of deposits → free marketing for project, 75% → $LGT liquidity.
  • Public Pool: No deposit cap, random multiplier 1x–7x, opens only when no project pools are active.
  • Dual‑Token Pool: Project contributes USDC + its own token. Users earn both $LGT and project token. 30% to project revenue, 40% buys project token (buy pressure), 30% to $LGT liquidity.
